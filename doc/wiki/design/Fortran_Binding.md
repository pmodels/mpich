# MPICH Fortran Binding

MPICH provides the MPI Fortran binding via `libmpifort(.so)`, the `mpifort` wrapper compiler script, and `mpi_fortran.h`. Fortran MPI programs are built using `mpifort`, which adds `-lmpifort` to the linker. The header `mpi_fortran.h` is for C programs that need Fortran interoperability features such as `MPI_Fint` and the `MPI_*_f2c`/`MPI_*_c2f` handle conversion functions.

There are three ways to use MPI in Fortran:
1. `include 'mpif.h'` — the F77 binding.
2. `use mpi` — the F90 binding.
3. `use mpi_f08` — the F08 binding.

Source code lives under `src/binding/fortran/`, with subdirectories `mpif_h/`, `use_mpi/`, and `use_mpi_f08/` corresponding to each binding. Code generation scripts are in `maint/`.

## F77 Binding

The F77 binding implements MPI functions in C, relying on the Fortran ABI calling convention and configure checked name mangling schemes. All parameters are passed by reference (`MPI_Fint *`), and an extra `ierr` parameter replaces the C return value.

### Name Mangling and Profiling Interface

Different Fortran compilers mangle symbol names differently:
    * `F77_NAME_LOWER_USCORE`: `gfortran`, `ifort/ifx`
    * `F77_NAME_UPPER`: Windows (Visual Studio/MSVC ecosystem), Cray & Unicos
    * `F77_NAME_LOWER`: IBM XL Fortran (AIX) & HP-UX
    * `F77_NAME_LOWER_2USCORE`: legacy `g77`

There are four compilation modes for `mpif_h/fortran_binding.c` (assuming under `F77_NAME_LOWER_USCORE`):

1. **Multiple weak aliases** (`HAVE_MULTIPLE_PRAGMA_WEAK` or `HAVE_ATTR_WEAK_ALIAS`):
    - `pmpi_send_`: via `#define mpi_send_ pmpi_send_`
    - 7 weak symbol aliases:
        `MPI_SEND`, `mpi_send`, `mpi_send_`, `mpi_send__`, `PMPI_SEND`, `pmpi_send`, `pmpi_send__`

2. **Single weak alias** (`HAVE_PRAGMA_WEAK_ALIAS`, `HAVE_PRAGMA_HP_SEC_DEF`, or `HAVE_PRAGMA_CRI_DUP`):
    - `pmpi_send_`: via `#define mpi_send_ pmpi_send_`
    - 1 weak symbol alias: `mpi_send_`

3. **No weak symbols, MPI pass** (`MPICH_MPI_FROM_PMPI` defined):
    - `mpi_send_`: as is

4. **No weak symbols, PMPI pass** (`MPICH_MPI_FROM_PMPI` not defined, no `USE_WEAK_SYMBOLS`):
    - `pmpi_send_`: via `#define mpi_send_ pmpi_send_` 


### Sentinel Constants via COMMON Blocks

MPI defines several sentinel constants (`MPI_BOTTOM`, `MPI_IN_PLACE`, `MPI_STATUS_IGNORE`, etc.) that are identified by address, not value. In Fortran 77, these are implemented using `COMMON` blocks so that both Fortran and C code can agree on the address.

In `mpif.h`, the constants are declared as variables in named COMMON blocks:

```fortran
COMMON /MPIPRIV1/ MPI_BOTTOM, MPI_IN_PLACE, MPI_STATUS_IGNORE
COMMON /MPIPRIV2/ MPI_STATUSES_IGNORE, MPI_ERRCODES_IGNORE
COMMON /MPIPRIVC/ MPI_ARGVS_NULL, MPI_ARGV_NULL
COMMON /MPIFCMB5/ MPI_UNWEIGHTED
COMMON /MPIFCMB9/ MPI_WEIGHTS_EMPTY
COMMON /MPIFCMBa/ MPI_BUFFER_AUTOMATIC
```

At initialization, `setbotf.f` calls `mpirinitc()`, passing these COMMON block variables by reference. The C function `mpirinitc_()` in `setbot.c` captures their addresses into C-side pointers (e.g., `MPIR_F_MPI_BOTTOM`, `MPI_F_STATUS_IGNORE`). The generated F77 wrapper functions then compare incoming buffer pointers against these stored addresses to detect sentinel usage and substitute the corresponding C constants.

### Key Files

- `src/binding/fortran/mpif_h/fortran_binding.c` — generated C implementations of all F77 MPI functions (generated by `maint/gen_binding_f77.py`).
- `src/include/mpif.h` — generated Fortran header that defines MPI constants as Fortran `PARAMETER` values and sentinel constants via `COMMON` blocks.
- `src/binding/fortran/mpif_h/mpi_fortran.h.in` — template for the C header providing `MPI_Fint`, `MPI_F08_status`, and handle/status conversion functions (`MPI_Comm_f2c`, `MPI_Status_c2f`, etc.).
- `src/binding/fortran/mpif_h/setbotf.f` — Fortran initialization subroutine that passes COMMON block addresses to C.
- `src/binding/fortran/mpif_h/setbot.c` — C function that captures COMMON block addresses for sentinel detection.

## F90 Binding

The F90 binding reuses the same C functions as the F77 binding for MPI procedure implementations. The difference is in how the API is exposed to Fortran: instead of `include 'mpif.h'`, users write `use mpi`, which loads a Fortran module (`mpi.mod`) that provides explicit interfaces and typed constants.

### Key Files

- `src/binding/fortran/use_mpi/mpi.f90` — the top-level `mpi` module, which re-exports from submodules.
- `src/binding/fortran/use_mpi/mpi_constants.f90` — generated MPI constants.
- `src/binding/fortran/use_mpi/mpi_base.f90` / `pmpi_base.f90` — generated MPI and PMPI function interfaces.

## F08 Binding

The F08 binding does not use C wrapper functions in the same way as F77/F90. Instead, it relies on `ISO_C_BINDING` to call C MPI functions directly from Fortran via `BIND(C)` interfaces. This avoids the Fortran ABI name-mangling complexity entirely.

### Type System

The F08 binding defines distinct derived types for each MPI handle (e.g., `TYPE(MPI_Comm)`, `TYPE(MPI_Datatype)`), each containing an integer `MPI_VAL` component. These types are `BIND(C)`, ensuring layout compatibility with the C `int` handles. Operator overloads for `==` and `/=` are provided for handle comparisons.

### Assumed-Shape Array Support (CFI_cdesc_t)

The F08 binding supports passing assumed-shape arrays (including array slices) as MPI buffers. This is implemented via `CFI_cdesc_t`, the C descriptor for Fortran arrays defined by the Fortran 2018 standard (`ISO_Fortran_binding.h`).

For MPI functions that take buffer arguments, an intermediate C wrapper accepts a `CFI_cdesc_t *` instead of a plain `void *`. The wrapper function `cdesc_create_datatype()` extracts the array layout (rank, extents, strides) from the descriptor and constructs an MPI derived datatype that describes the memory layout, using `MPI_Type_contiguous` and `MPI_Type_create_hvector`. The Fortran side declares these wrappers in `mpi_c_interface_cdesc.f90`.

### Special Constants

Fortran link-time constants such as `MPI_BOTTOM`, `MPI_IN_PLACE`, `MPI_STATUS_IGNORE`, and `MPI_ARGV_NULL` require special handling since they must be recognizable sentinel values in C. These are defined as Fortran arrays with `BIND(C)` names and initialized at runtime via getter functions (e.g., `MPIR_F08_get_MPI_BOTTOM`).

### Key Files

- `src/binding/fortran/use_mpi_f08/mpi_f08.f90` — generated top-level `mpi_f08` module with all MPI procedure interfaces.
- `src/binding/fortran/use_mpi_f08/mpi_f08_types.f90` — generated handle types, `MPI_Status`, operator overloads, and `MPI_Sizeof`.
- `src/binding/fortran/use_mpi_f08/mpi_c_interface.f90` — aggregator module combining all C interface submodules.
- `src/binding/fortran/use_mpi_f08/mpi_c_interface_types.f90` — generated C-side type definitions (`c_comm`, `c_datatype`, `MPI_C_Status`, etc.).
- `src/binding/fortran/use_mpi_f08/mpi_c_interface_nobuf.f90` — generated `BIND(C)` interfaces for MPI functions without buffer arguments.
- `src/binding/fortran/use_mpi_f08/mpi_c_interface_cdesc.f90` — generated `BIND(C)` interfaces for MPI functions with buffer arguments (using `CFI_cdesc_t`).
- `src/binding/fortran/use_mpi_f08/mpi_c_interface_glue.f90` — handwritten interfaces for string conversion utilities and initialization.
- `src/binding/fortran/use_mpi_f08/mpi_f08_link_constants.f90` — Fortran definitions of special sentinel constants.
- `src/binding/fortran/use_mpi_f08/wrappers_c/cdesc.c` — C implementation of `cdesc_create_datatype()`.
- `src/binding/fortran/use_mpi_f08/wrappers_c/f08_cdesc.c` — generated C wrappers for buffer-taking MPI functions.
- `src/binding/fortran/use_mpi_f08/wrappers_c/utils.c` — getter functions for special constants and string conversion utilities.

## Code Generation

Most Fortran binding source files are generated from MPI function definitions. The generation scripts are:

- `maint/gen_binding_f77.py` — generates `fortran_binding.c`, `mpif.h`, and `fortran_profile.h`.
- `maint/gen_binding_f08.py` — generates all F08 binding files (types, interfaces, wrappers, constants).
- `maint/local_python/binding_f08.py` — shared library of F08 generation functions used by `gen_binding_f08.py`.

The F90 binding files (`mpi_constants.f90`, `mpi_base.f90`, `pmpi_base.f90`) are also generated, using the F77 generation infrastructure.

## NOTES

* The `ierr` argument:
    * It is not optional using `mpif.h`.
    * It is not optional with `use mpi` in our implementation, although MPI-4.0 made it optional.
    * It is optional in `use mpi_f08` with the `OPTIONAL` attribute.
* The `status`:
    * It is an INTEGER array of size `MPI_STATUS_SIZE` with `mpif.h` or `use mpi`.
    * It is a derived type `Type(MPI_Status)` in `use mpi_f08`.
